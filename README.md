# lingooasis_introduction

## 紹介サイト

日本語・英語のランディングページはここで管理します。`index.html` が日本語版、`en/index.html` が英語版です。画像とスタイル、スクロール演出用スクリプトも同じディレクトリに含めています。

ローカルで確認するには、リポジトリのルートから次を実行します。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8765/` を開くと日本語版、`http://127.0.0.1:8765/en/` を開くと英語版を確認できます。
